# Visualization output directory

Default output folder for HTML and assets produced by the scripts in `satviz/scripts/`.
Generated files are not checked into git; create visualizations with the commands in
`satviz/README.md`.

## Getting started

1. Run a visualization script (example: path at one time step):
   ```
   cd satviz/scripts
   python visualize_path.py
   ```

2. Open the generated `.html` under this directory in a browser (Cesium token required;
   see `satviz/README.md`).
